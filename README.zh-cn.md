[Rocket.Chat](https://rocket.chat) 是一个基于 JavaScript 开发的开源完全可定制通信平台，专为对数据保护有高要求的组织打造。

我们是团队沟通的终极**免费开源解决方案**，无论您的同事、其他公司或客户如何与您联系，都能实现实时对话。这将提高工作效率和客户满意度。

每天，来自150多个国家的数千万用户以及德国铁路、美国海军和瑞士信贷等组织都信任Rocket.Chat来保持其通信的完全私密性和安全性。

# 🚀 产品服务 - 自托管和云端

Rocket.Chat 提供四大核心产品服务：

💬 **团队协作** - 安全的内部和跨公司协作的单一平台。

🎯 **全渠道客户服务** - 无论客户如何与您联系，都能进行无缝互动。

🦾 **聊天引擎** - 在您的移动应用或Web应用中创建定制化的消息体验。

🤖 **应用市场** - 选择各种应用和原生集成，帮助您的企业更有效地沟通。

# 🛠️ 本地开发

您可以按照以下指南为您的操作系统设置Rocket.Chat服务器开发环境：


- [Linux](https://developer.rocket.chat/docs/linux)：了解如何在任何Linux发行版上设置Rocket.Chat服务器开发环境。

- [Mac OSX](https://developer.rocket.chat/docs/mac-osx)：学习如何在Mac上设置Rocket.Chat服务器开发环境。

- [Windows 10](https://developer.rocket.chat/docs/windows-10)：在Windows上设置Rocket.Chat服务器开发环境。

- [Gitpod](https://developer.rocket.chat/docs/gitpod)：使用预配置的在线开发环境来开发Rocket.Chat服务器。

> 请访问[Rocket.Chat环境设置指南](https://developer.rocket.chat/docs/server-environment-setup)了解更多信息。
